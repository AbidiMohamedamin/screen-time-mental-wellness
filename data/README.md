# Data

`ScreenTime_vs_MentalWellness.csv` — *Screen Time vs Mental Wellness Survey – 2025*, published on Kaggle:
https://www.kaggle.com/datasets/adharshinikumar/screentime-vs-mentalwellness-survey-2025

400 participants × 15 variables (demographics, work/leisure screen time, sleep, stress, exercise,
social time, productivity and a 0–100 mental wellness index). No missing values.

The file is redistributed here only for reproducibility; all rights belong to the original author.
Check the licence on the Kaggle page before reusing it.
